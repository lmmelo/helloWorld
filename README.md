# Block Breaker Game

A classic Breakout-style arcade game built with Python and Pygame!

## Description

Block Breaker is a fun arcade game where you control a paddle to bounce a ball and break all the blocks. Use your reflexes to keep the ball in play and clear all the blocks to win!

## Features

- Classic Breakout gameplay
- Colorful blocks arranged in 6 rows
- Score tracking system
- Multiple lives (3 lives per game)
- Ball physics with paddle positioning affecting bounce angle
- Win/lose conditions with restart functionality

## Installation

1. Make sure you have Python 3.7+ installed
2. Install the required dependencies:

```bash
pip install -r requirements.txt
```

Or install pygame directly:

```bash
pip install pygame
```

## How to Play

Run the game with:

```bash
python block_breaker.py
```

### Controls

- **Left Arrow**: Move paddle left
- **Right Arrow**: Move paddle right
- **Space**: Restart game (after game over or winning)
- **Escape**: Quit game

### Objective

- Break all the blocks to win!
- Don't let the ball fall below the paddle
- You have 3 lives - make them count!
- Each block is worth 10 points

## Gameplay Tips

- Position the paddle to control where the ball bounces
- Hitting the ball with different parts of the paddle changes its angle
- Try to break the top rows first for maximum points
- Watch the ball speed - it can get tricky!

Have fun breaking blocks!
